# 越南语成为界面回退语言

[English](guide.md) | 中文

## 变更

web GUI 现在在英文、中文、日语、西班牙语、法语、德语、俄语和巴西葡萄牙语之外新增越南语（`vi`）locale。插件元数据、Desktop 外壳与安装程序也提供越南语资源。此前浏览器未请求任何内置语言时会打开英文，现在会打开越南语，并且语言选择器把越南语作为默认选择排在首位。英文仍是字典链的终结回退：内置字典缺少某个键时仍按英文查找，因此查找行为不变。所有语言的用户以及语言包作者都会观察到这一变化。任何注册 `vi` 语言 id，或为 `common`、`settings.locale` 注册 `vi` 字典的第三方 client 插件，现在都会以“已注册”错误失败。

## 迁移

1. 若希望浏览器语言列表不匹配任何内置语言的浏览器保持英文界面，请在“设置 → 常规”中选择英文，或在 `$DSH_HOME/cordis.patch.yml` 的 `locale` 设置命名空间下添加 `locale.preference: en`。已存储的偏好仍优先于浏览器检测，因此既有选择无需改动。
2. 从第三方语言包中删除 `ctx.locale.addLanguage({ id: 'vi', … })` 调用以及任何 `vi` 字典；内置字典已占用这些位置。
3. 用请求未内置语言的浏览器重新加载，确认界面以越南语打开；再切换到英文，确认该选择在重新加载后仍然保留。
